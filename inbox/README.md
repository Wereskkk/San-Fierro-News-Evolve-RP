# `inbox/` — приём фотографий для выпусков San Fierro News

Памятка для главреда.

## Суть папки

Это **очередь загрузки, а не архив**. Сюда главред кладёт фотографии для готовящихся
выпусков (расследования, фоторепортажи, еженедельники); редакция забирает их в работу
и очищает папку. Так мы не упираемся в лимит вложений чата (10 фото за сообщение):
веб-интерфейс GitHub принимает до 100 файлов одним коммитом, а догружать можно
сколько угодно раз.

## Как загрузить фото (веб GitHub)

1. Открыть папку: <https://github.com/Wereskkk/San-Fierro-News-Evolve-RP/tree/main/inbox>
2. `Add file` → `Upload files`, перетащить фотографии.
3. Оставить `Commit directly to the main branch` → `Commit changes`.
4. Партий может быть несколько — каждая своим коммитом. Когда загружено всё,
   дать редакции команду (например, «всё загружено, приступай»): по правилу
   HANDOVER §7 вёрстка не начинается до получения всех партий и явной команды.

Имена файлов — по спецификации выпуска (например, «ДОКАЗАТЕЛЬСТВО №01 …» или
«Rauf Falk готовит автомобиль к эвакуации со штрафстоянки..jpg»): редакция
использует имена как карту к ТЗ и самовольно не переименовывает.

## Что делает редакция после получения

1. Забирает фото из `inbox/` локально **байт-в-байт**, без изменений, каталогизирует партию.
2. Очищает папку отдельным коммитом через `protection/scripts/publish.sh`:
   в `inbox/` остаётся только этот README. Следующий выпуск загружается в пустую папку —
   партии не путаются.
3. История git хранит загруженные файлы навсегда (force-push запрещён) — очистка
   касается только текущего дерева, и это нормально.

## Техническое (для будущих редакторов)

- Папка **исключена из guard G1** (`STAGING_PREFIXES`, как `anna-malboro/`):
  исчезновение файлов после получения — штатный результат, а не нарушение.
- Папка **не входит в `manifest.json`** (манифест — реестр опубликованных страниц корня)
  и **не участвует в тегах** (`make_release_tags.sh` работает только по `.html`).
- Фотографии из `inbox/` — сырьё, а не опубликованные файлы: в выпуск они попадают
  обработанными и вшитыми base64 в HTML. Напрямую из папки ничего не публикуется.

По содержимому партий — к главреду; по ритуалу получения/очистки — `investigation/work/inbox_pull.sh` у редакции. ★
