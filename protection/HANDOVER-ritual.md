# Блок для вставки в HANDOVER.md (ритуал защиты)

## В §2 «Репозиторий и публикация» добавить после пункта «Конец: …»:
- **Ритуал опечатывания выпуска (обязателен):** выпуск → коммит → тег → анонс → манифест → снапшот.
  1) коммит с датой выпуска в тот же день (дата коммита = публичное доказательство первенства);
  2) `git tag v-<имя-файла-без-.html> && git push -q origin --tags` (теги не удалять и не двигать никогда);
  3) анонс на форуме/Discord Evolve RP в день выхода (третья независимая датированная метка);
  4) `python3 protection/scripts/make_manifest.py` → коммит `manifest.json` тем же коммитом выпуска;
  5) снапшот НАШЕЙ опубликованной страницы на web.archive.org (Save Page Now) — независимая от GitHub
     датированная копия; если страница ещё не проиндексирована — снять сырой файл с GitHub raw.
- **Защитные слои в каждой странице:** копирайт-комментарий в `<head>` (из шаблонов), CSS-штамп
  `/* SFN-DESIGN-NNN: slug · дата */`, невидимый маркер `<!-- SFN · 2026 · NNN · slug -->` перед `</body>`,
  строка подвала «дизайн и вёрстка — редакция San Fierro News». Номера NNN и slug — таблица в
  `protection/snippets.md`; новый выпуск = следующий номер, запись в таблицу тем же коммитом.
- **Юридический статус:** корень репозитория содержит `LICENSE` (CC BY-NC-ND 4.0 на редакционный слой;
  игровые кадры лицензией не покрываются — они собственность правообладателей игры).
  Видимый текст страниц НЕ содержит юридических терминов (RP-чистота, §6).

## В §7 «Рабочий процесс» добавить:
- **Мониторинг копий, 10 минут в неделю (понедельник):** открыть страницы конкурирующих редакций →
  просмотр кода → поиск маркеров: `SFN-DESIGN`, `SFN ·`, имена из реестра сигнатурных классов
  (`protection/snippets.md` §6), строку подвала, структуру `.pcard/.plate/.jackpot`.
  Нашли совпадение → НЕ писать им, НЕ комментировать: фиксировать пакет доказательств
  (`protection/evidence-and-complaints.md` §2) и докладывать гендиректору одним сообщением со ссылками.
- **Рефакторинг вёрстки:** упрощение/переименование сигнатурных классов допустимо, но запись в реестре
  `snippets.md` §6 не удаляется — помечается «имя жило до ДД.ММ.ГГГГ», форензик-след не теряется.
- **Ретро-правки защиты** (штампы в уже опубликованные страницы, правки LICENSE) — только по явной
  команде гендиректора, одним коммитом, с обновлением манифеста.
